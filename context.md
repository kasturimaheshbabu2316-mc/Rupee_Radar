# Project Context: RupeeRadar

## Overview

RupeeRadar is an AI-powered personal finance assistant designed to help users understand their spending habits by analyzing their bank statement data. It aims to solve the problem of messy, inconsistent transaction descriptions that make manual categorization difficult.

## Objective

Create an end-to-end solution that converts raw financial transaction data into meaningful personal finance insights. The application should answer key questions regarding:

- Biggest spending categories
- Monthly spending totals
- Recurring subscriptions or EMIs
- Largest transactions
- Top spending behavior insights

## Core Features

1. **Data Ingestion:** Accept bank statement data as input.
2. **Data Extraction & Cleaning:** Extract and clean transactions into a structured format.
3. **Categorization:** Automatically categorize transactions into meaningful groups (e.g., Food, Travel, Shopping, Bills, EMI, Subscriptions, Salary, Rent, Investments, Other).
4. **Recurring Payment Detection:** Identify recurring transactions such as subscriptions, EMIs, rent, SIPs, or insurance payments.
5. **Financial Metrics Calculation:** Calculate key metrics including total income, total spend, savings, top categories, and biggest transactions.
6. **Insight Generation:** Generate clear, human-readable spending insights using actual transaction amounts.
7. **User Interface / Reporting:** Present the final output through a simple user interface, dashboard, or downloadable report.

## Expected Deliverables

A deployed or locally runnable working prototype that demonstrates:

- Cleaned transaction data
- Categorized expenses
- Recurring payment detection
- A spend summary dashboard
- At least three personalized financial insights
- A final report or visual summary that can be shared

## Constraints & Considerations

- **Priority:** Prioritize a working end-to-end prototype over perfect support for every bank format.
- **Technology Stack:** Flexible. Participants may choose their own technology stack and implementation approach.
- **Privacy:** Ensure privacy-conscious handling of sensitive financial data.
- **Handling Real-world Data:** Ability to handle real-world messy transaction descriptions accurately.
